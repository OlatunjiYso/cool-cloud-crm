# cool-cloud-crm
A cool cloud crm utility


## Getting Started

```bash
npm install
```

## Run It

```bash
npm start "Company Name"
```

## Example

```bash
npm start "SunTrust"
```

Output:

```json
{
    "id": "2467812",
    "crmType": "DEALCLOUD",
    "matchedName": "SunTrust",
    "matchedDomain": "suntrust.com",
    "crmUrl": "https://resolve.dealcloud.com/#/Company/2467812"
}
```
